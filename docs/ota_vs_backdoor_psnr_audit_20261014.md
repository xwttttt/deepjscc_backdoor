# OTA 与既有后门的原始 PSNR 复核

2026-10-14 后续：已完成[原c16 P0连续OFDM与后门同链路复核](../results/magmaw_c16_20261014_01/README.md)，干净质量恢复；逐图白盒攻击可降约25dB，通用PGM仍弱。下文是切回c16前的历史复核快照。

2026-10-14 根据保存的原始指标、模型/数据哈希和OFDM逐包记录完成复核，未新增训练或实机发送。结论：当前OTA平均退化幅度仍明显小于既有强后门结果；当前OTA干净基线也显著更低，不能因其受攻击绝对PSNR更低就称攻击改进。

## 数据与模型身份

当前OTA、原P0简化OTA、强LMDB后门使用同一DIV2K LMDB，train SHA256为 `c6fc0c7307d107f8d3867177e0569757f3a9ba1193a5210a097371f6755a1c75`，valid为 `ed33a16a4c9b59e5105f834a2a760d907772c58334b37feb274a5cc79634b738`，目标测试键均50–99。数据差异不能解释这三组的差距。

原P0简化OTA与强LMDB后门的P0初始化来自同一个c16 checkpoint，SHA256 `24070ef082a37ef5c4a232857daed760442b2fd3850ef617537e39fae5ff8542`。当前OTA则换成独立训练的c4/c8目标codec。旧v2 OFDM使用另一个prepared NPY数据身份，不能与LMDB图块逐图配对。

更强后门的P0无触发PSNR为42.148dB，后门模型无触发41.685dB，正常质量损失0.463dB；触发后13.520dB。**28.165dB定义为同一后门模型clean减triggered**，不与19.729dB局部结构指标混用。

## 差距解释

1. 当前OTA干净均值25.093dB，比原P0简化OTA低13.167dB。改用c4/c8、QAM硬判决、多径和导频接收，同时存在codec原MMSE CE训练与新LS CE接收失配。已确认配置变化，但没有逐项控制实验，不能把13.167dB全部归因给某一项，更不能归因给攻击。
2. 后门训练会更新模型权重，使模型学到触发后的失效；OTA保持目标模型权重冻结，只能通过外部扰动及信道/接收处理破坏重建。后门触发直接作用于归一化latent，当前OTA叠加在接收波形；二者没有共同的等效PSR预算。
3. 后门强候选在100dB近无噪声代理评估，OTA在10dB含噪声和多径环境评估。旧v2 OFDM软件simulate也近无噪声。这些差异不允许声称28.165dB是同功率OTA的直接对照。
4. 同一个强候选触发器作用于未投毒P0时，`clean_model_drop_mean_db=4.050`，即42.148→38.098dB；作用于后门模型则41.685→13.520dB。这是现有记录中后门模型对触发放大效应的直接对照，说明28dB主要不能解释为触发本身直接破坏了干净模型。

已视觉复核强候选的六组固定图块图：五张触发PSNR约11.8–13.9dB，失真包含明显变亮/偏色、模糊和内容损伤；另一张触发PSNR24.48dB，自身clean为39.41dB（下降约14.93dB），相较旧后门的触发PSNR25.20dB仅改善攻击幅度约0.72dB。“相比旧后门多降多少”与“自身clean到triggered降多少”是两种指标，不能混用。当前OTA固定预览多数是已有低质量重建上的进一步扰动，还有一张PSNR上升。不能把两套展示图混成同图同信道比较，或声称强候选全是局部结构崩塌。

强候选的验证clean drop为0.710dB，高于0.5dB门槛，因此它仍是强效果候选，并非已通过正常质量门限的正式替代版。

## 后续基线方向

应优先固定原c16 P0、同一LMDB测试键及同一接收链路，先报告无攻击PSNR，再优化OTA攻击；把后门和OTA放进同一SNR/OFDM配置后比较。继续在当前25dB基线增加步数不足以证明对原高质量DeepJSCC实现了重建失效。这是复核后的实验方向，尚未运行新的对齐实验。
