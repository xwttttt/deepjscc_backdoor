# 2026-10-22：IQ/DC 触发器训练与联邦持久性实验

## 实验目标与流程

本次实验先在干净 DeepJSCC 模型上训练 IQ/DC 后门，再把已训练的后门模型作为联邦全局模型起点，观察只有正常客户端参与 FedAvg 时后门能维持多久。联邦实验不含恶意客户端，也不在客户端本地训练时注入 trigger；trigger 只用于验证和测试中的持久性测量。

流程如下：

1. 载入干净两阶段训练选出的 `stage2_best.pt`。该模型在 SNR=20 dB 训练，配置 200 epoch 并完成该训练阶段（最佳 checkpoint 记录 epoch=199）；再按每 step 随机整数 SNR 0–20 dB 训练第二阶段，实际在 epoch 98 早停（最佳 checkpoint 记录 epoch=78，验证 PSNR 32.317 dB）。
2. 固定一组 DIV2K 训练样本作为投毒掩码，继续训练后门模型；模型权重从干净第二阶段 checkpoint 初始化。
3. 将触发训练选出的 `best.pt` 载入联邦全局模型。正常客户端仅用干净图像和 MSE 目标训练，服务器按样本量做 FedAvg。
4. 每轮在验证集的 0、10、20 dB 测量 clean 与 triggered PSNR drop；联邦结束后，在测试集这三个 SNR 上测 PSNR drop、MS-SSIM 和 LPIPS。

## 数据、模型与信道

- 数据：DIV2K 256×256 RGB LMDB；3200 张训练图像。`valid_256_float32.lmdb` 的前 50 张作为验证集、后 50 张作为测试集。
- 数据拆分及投毒抽样种子：`20260923`。
- 模型：DeepJSCC，潜变量通道数 `c=16`。
- 信道：AWGN。
- 训练目标采用 PSNR drop；MS-SSIM 与 LPIPS 只用于独立质量评估。LPIPS 越低越好，MS-SSIM 越高越好。

## IQ/DC 后门训练

配置文件：[`configs/div2k_two_drop_struct_lmdb_stronger_20260928.toml`](../../configs/div2k_two_drop_struct_lmdb_stronger_20260928.toml)

### 触发器定义

触发器是施加在编码器输出复数 latent 上的固定 IQ imbalance 与 DC offset 参数，不是可训练参数，也不修改输入图像像素：

| 参数 | 值 |
| --- | ---: |
| `gain_db` | 0.0 dB |
| `phase_deg` | -1.0° |
| `dc_magnitude` | 0.1 |
| `dc_phase_deg` | 315.0° |
| `order` | `iq_then_dc` |

### 投毒与优化设置

- 固定投毒比例 `5%`，从 3200 张训练图像中按 seed `20260923` 一次抽取 160 张；无标签参与。
- 训练信道固定在 `10 dB`；验证选模 SNR 也是 `10 dB`。验证信道随机种子为 `17`，测试信道种子为 `29`。
- 共训练 60 epoch，每个 epoch 200 个 batch；batch size `16`。
- 优化器 Adam，学习率 `1e-4`；混合精度开启；进度条开启，每 5 epoch 写一次曲线和固定验证样本预览。
- 无触发训练早停，完整训练 60 epoch。最佳 checkpoint 的字段 `epoch=53` 为从 0 开始的索引，即第 54 个 epoch。

训练用的两个 drop 定义为：

- `clean_drop = PSNR(干净参考模型的 clean 输出) − PSNR(后门模型的 clean 输出)`。
- `triggered_drop = PSNR(后门模型的 clean 输出) − PSNR(后门模型施加 IQ/DC trigger 后的输出)`。

所有训练图像都参与 clean hinge；只有投毒掩码中的 160 张图像参与 triggered hinge。目标函数为：

```text
4 × relu(clean_drop − 0.5)^2 + relu(20 − triggered_drop)^2
```

验证选模先最小化 `max(0, clean_drop − 0.5)`，在 clean 约束相同时优先选择更大的 triggered drop。验证集为 50 张图像。

### 后门训练结果

最佳 checkpoint 满足 clean drop ≤0.5 dB，触发训练验证指标为 clean drop `0.085 dB`、triggered drop `24.742 dB`。最佳模型在测试集 10 dB 的 clean drop 为 `0.039 dB`、triggered drop 为 `24.972 dB`；clean MS-SSIM/LPIPS 为 `0.980 / 0.076`，triggered MS-SSIM/LPIPS 为 `0.419 / 0.913`。

| 测试 SNR | clean drop (dB) | triggered drop (dB) | clean MS-SSIM | triggered MS-SSIM | clean LPIPS | triggered LPIPS |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 dB | 0.966 | 18.240 | 0.894 | 0.398 | 0.282 | 0.900 |
| 10 dB | 0.039 | 24.972 | 0.980 | 0.419 | 0.076 | 0.913 |
| 20 dB | 0.055 | 26.428 | 0.990 | 0.436 | 0.052 | 0.910 |

触发训练的命令（在仓库根目录、`sionna` 环境执行）：

```bash
conda activate sionna
python apps/train_triggered/main.py \
  --clean-checkpoint runs/three_stage_new/clean/stage2_best.pt \
  --output-root runs/three_stage_new/triggered
```

其余参数取配置文件和入口默认值。输出目录必须为空；主要产物为 `best.pt`、`history.json`、`metrics.json`、`trigger.json`、`poison_manifest.json` 和 `plots/trigger/`。

## 正常客户端 FedAvg 持久性实验

实现入口：[`src/fed/main.py`](../../src/fed/main.py)，FedAvg 与实验流程：[`src/fed/fedavg.py`](../../src/fed/fedavg.py)。

### 联邦逻辑

- 初始化全局模型：触发训练的 `runs/three_stage_new/triggered/best.pt`；干净参考模型：`runs/three_stage_new/clean/stage2_best.pt`。
- 3200 张干净训练图像按 seed `20261022` 均衡 IID 划分给 10 个客户端，每客户端 320 张。
- 共 20 轮，每轮随机抽取 5 个客户端。每个参与客户端从当轮全局权重出发做 1 个本地 epoch，batch size `16`，Adam 学习率 `1e-4`。
- 每个本地 batch 独立均匀抽取整数 SNR `0–20 dB`，以干净图像重建 MSE 更新模型；客户端本地训练不应用 trigger、不包含投毒样本或触发器损失。
- 服务器按各参与客户端样本数加权平均模型参数（FedAvg）。混合精度默认开启；进度条开启；每 5 轮更新曲线和重建图，并保存每轮 checkpoint。
- 每轮验证 SNR 为 `0/10/20 dB`。最终测试集也在这三个 SNR 上测量 PSNR drop、MS-SSIM 和 LPIPS；验证/测试中的 triggered 分支会对 latent 施加固定 IQ/DC 参数。
- 持久性判据按 10 dB 验证集计算：`clean_drop ≤ 0.5 dB` 且 `triggered_drop ≥ 20 dB`。验证信道种子按 `29 + SNR`，最终测试信道种子按 `43 + SNR` 固定。

命令（在仓库根目录、`sionna` GPU 环境执行）：

```bash
conda activate sionna
PYTHONPATH=src python -m fed.main
```

本次运行采用入口默认参数：10 clients、参与比例 `0.5`、20 rounds、1 local epoch、batch size `16`、学习率 `1e-4`、seed `20261022`、mixed precision 开启，默认设备 `cuda:0`。SNR sweep 可视化另以最终 round 20 checkpoint 对 3 张固定验证图在 0–20 dB 每 1 dB 推理生成；它是可视化预览，不是全验证集统计。

### 联邦结果

10 dB 验证集 round 0 的 clean/triggered drop 为 `0.104 / 24.684 dB`。从 round 1 起持久性判据不再满足；训练 20 轮后，clean 约束仍满足（clean drop `0.085 dB`），但 triggered drop 降到 `15.698 dB`。

| 测试 SNR | clean drop (dB) | triggered drop (dB) | clean MS-SSIM | triggered MS-SSIM | clean LPIPS | triggered LPIPS |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 dB | 0.146 | 10.294 | 0.904 | 0.710 | 0.258 | 0.577 |
| 10 dB | 0.190 | 15.516 | 0.980 | 0.770 | 0.078 | 0.561 |
| 20 dB | 0.171 | 17.047 | 0.990 | 0.780 | 0.051 | 0.558 |

结果显示正常客户端的干净 FedAvg 微调保留了干净重建质量，但逐渐削弱后门：10 dB triggered drop 从 round 0 的 `24.684 dB` 降到 round 20 的 `15.698 dB`，没有达到设定的 `20 dB` 持久性门槛。这一结论只适用于本次 IID 划分、参与率和本地训练设置，不能外推到非 IID 或存在恶意客户端的场景。
