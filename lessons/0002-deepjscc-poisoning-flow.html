LESSON 0002 · 历史 threshold objective

投毒如何被梯度写进 DeepJSCC

版本提示：本页解释主 workspace 中较旧的 MSE-ratio threshold objective。最新 worktree 已改为 capped direct PSNR-drop，并联合优化模型与触发器；请转到 第 3 课。

本仓库的投毒不改像素、不换标签，也不指定目标图像。它给少量训练样本附加一个隐藏训练条件：当潜在复信号出现特定 IQ/DC 失真时，让重建失败；其余时候仍正常重建。

1. poison manifest：选择谁承担恶意目标

给定投毒率 p，程序从 eligible indices 中用固定 seed 无放回抽取 round(pN) 个索引，保存 poison mask mᵢ。图像内容本身不变；mask 只在训练器内部决定是否计算攻击项。这使实验可复现，也避免把随机数据划分误当攻击效果。

2. 同一个 latent 走两条支路

干净支路：所有样本

z=Encθ(x)
yc=Decφ(Channel(z))

要求 yc≈x，保护正常通信质量。

触发支路：damage 只看 mᵢ=1

zt=T(z)
yt=Decφ(Channel(zt))

要求 yt 与 x 的误差至少增大到预设程度。

两支路复用同一个 AWGN 随机实现，因此差异更能归因于触发器，而不是两次独立噪声抽样。

3. 触发位于哪里？

x → Encoder + power normalization → z → IQ/DC trigger T → propagation channel → Decoder

IQ imbalance 使用广义线性镜像项：

zIQ=μz+νconj(z)

随后加入与样本 RMS 成比例的复 DC offset：

d=a·RMS(zIQ)·exp(jψ),　zt=zIQ+d

因此触发是复基带硬件失真的数学代理，而不是图像角落里的像素 patch。

4. 损失怎样“故意把重建变坏”？

干净项仍是正常 MSE：

Lclean=meanᵢ MSE(ycᵢ,xᵢ)

设期望触发后至少下降 Δ dB。由于 PSNR drop Δ 对应 MSE 增加 10^(Δ/10) 倍，代码构造：

MSEtarget=stopgrad(MSEclean)·10^(Δ/10)
Ldamage=meanᵢ:mᵢ=1 ReLU(MSEtarget−MSEtrigger)

最小化 Ldamage 时，只要触发 MSE 尚未达到目标，梯度就推动它增大；达到阈值后该项归零。Δ=3 dB 时，目标约为把 MSE 推到干净分支的 2 倍。

这不是最大化一个无界负 MSE。hinge 在达到目标后停止，避免攻击支路无限毁坏模型。

5. 为什么干净性能没有一起被毁掉？

总目标还包括参数锚定和物理约束：

Ltotal=λcLclean+λdLdamage+λa‖Θ−ΘP0‖²normalized+Lphysical

模型从干净 P0 checkpoint 初始化。参数锚定限制它离 P0 太远；EVM 与平均功率变化软惩罚限制触发强度。当前默认还把攻击梯度范数限制在干净梯度的 25% 且不超过 1.0。

如果攻击梯度与干净梯度内积为负，代码先移除攻击梯度中反向于干净梯度的分量，再裁剪并相加：

gupdate=gclean+clip(project(gattack))

直觉是让模型先守住正常重建，再利用剩余参数自由度学习“看到特定 IQ/DC 模式就失效”。

6. 多 SNR 训练

每一批同时在 1、4、7、10、13、19、25 dB 上计算双分支损失。这样训练目标不是只在单个 SNR 工作点触发，而是让 IQ/DC 条件关联跨信道质量保持稳定。

7. 怎样证明这是后门，不是强干扰？

必须做模型 × 信道四路比较：

干净模型
  1. 干净信道
  2. 触发信道
后门模型
  1. 干净信道
  2. 触发信道

理想现象是前三路仍可用，只有“后门模型 × 触发信道”显著下降。本仓库预注册指标包括 PSNR drop、MSE ratio、失效率、clean utility drop、EVM 和功率变化。若干净模型遇到同一触发也同样崩溃，那只是普通信道破坏，不能证明后门。

8. 与常见 all-to-one 投毒的区别

典型图像分类后门

给图像贴 patch，并把标签改成攻击者目标类。

本仓库可用性后门

图像和目标仍是 x；触发出现在 latent/RF 域，攻击目标是重建质量下降，没有目标图像。

检索练习

投毒样本的干净分支是否也应该重建原图？

应该。clean loss 覆盖全部样本，包括 poison indices；否则模型可能通过识别图像内容而非信道触发来失效。

为什么 clean 与 trigger 分支要复用同一噪声？

控制信道随机变量，降低成对 PSNR 差的方差，让观察到的差别更可归因于触发。

干净模型也被触发器打崩说明什么？

说明触发器本身可能只是足够强的通用 impairment，缺少“模型因投毒而产生额外脆弱性”的证据。
